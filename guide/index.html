攻略の要点

ビームは近いほど強い

ビーム兵器の遠隔攻撃は最大射程で威力が半分になります。Gダッシュは約4マスより遠いと近接攻撃の方が強くなります。

戦艦への攻撃は必ず当たる

戦艦には命中判定がありません。ただし防御ゲージがビームと主砲のダメージを大きく減らすので、実弾機や近接攻撃で攻めるのが効率的です。

撃破されたパイロットは戻らない

ユニットが撃破されると乗っていたパイロットは必ず戦死します。HPが50%を切ると自動で帰艦しますが、危ない機体は早めに「帰艦」させましょう。

旗艦を失えば即ゲームオーバー

作戦目標を達成できなくてもゲームは続きます（分岐が変わるだけ）。負けになるのは旗艦を失ったときだけです。

功績で旗艦が大きくなる

敵艦+10、敵ユニット+3の得点が累計され、一定に達すると基地で新しい旗艦が配備されます。搭載できるユニットも増えます。

CONDITION 400 未満は出撃不可

宇宙に出ている間コンディションは下がります。ユニットから降ろして控えにすると回復します。毎ミッション開始時に満タンに戻ります。

第1部戦闘のしくみ

1戦闘の流れ BATTLE COUNT

戦闘はリアルタイムで進み、画面の Battle Count が1つ進むたびに各ユニットのゲージが溜まります。ゲージが満タンになると、そのユニットは1マス移動するか、1回攻撃します。以下「カウント」はこの Battle Count のことです。マップは 90×120 マスです。

ユニット

移動ゲージ += min(移動速, 操縦能力) // 500で1マス移動 攻撃ゲージ += min(攻撃速, 操縦能力) // 2000で1回攻撃
  • 1マス移動にかかるカウントは 500 ÷ 移動速、攻撃の間隔は 2000 ÷ 攻撃速。パイロットの操縦能力が機体の値より低いと、そちらで頭打ちになります。
  • 攻撃の番が来ても撃てる相手がいないと、溜めたゲージは 499 まで戻されます。
  • 推進剤は移動の番が来るたびに1減ります（「停止」命令のときだけ減りません）。0になると移動ゲージは1カウントに10しか溜まりません。

戦艦

出力 = 機関 + 防御 + 主砲 // 3つに配分 移動ゲージ += 速度 × 機関 ÷ 10 // 5000で1マス 防御ゲージ += 防御 ÷ 5 − 6 // 0〜1000 主砲ゲージ += 主砲 ÷ 5 − 6 // 1000で発射、発射後0
  • 配分30でゲージは増えも減りもせず、30未満だと減っていきます。配分100で1カウント +14 です。
  • 主砲ゲージが満タンでも撃つ相手がいなければ、満タンのまま残ります。
  • 出撃直後の配分: 出力160未満の艦は機関「出力−60」、防御と主砲が30ずつ。出力160以上の艦は機関100、残りを防御と主砲で半分ずつ。ゲージは満タンで始まります。

2攻撃とダメージ DAMAGE

  • 隣接していれば近接攻撃、離れていれば遠隔攻撃。斜めを含む周囲8マスに相手がいると、どの命令でも近接攻撃値が使われます。
  • 距離は直線距離 √(横の差² + 縦の差²) です。射程は「距離²」で判定され、データ上の射程値 R に対し最大射程は √R マスです。ユニットは「距離² < R」のときだけ撃てるので、ちょうど最大射程のマスからは撃てません（戦艦は「距離² ≦ R」で撃てます）。
  • 遠隔攻撃が最も近い位置はまっすぐ2マス（距離2.0）です。

攻撃力

// 近接攻撃（隣接）: 距離の影響なし 攻撃力 = 近接攻撃値 // 遠隔攻撃: ビーム兵器（威力減衰あり）の機体と、すべての戦艦主砲 攻撃力 = 遠隔攻撃値 × (1 − 0.5 × 距離 ÷ 最大射程) // 遠隔攻撃: 実弾兵器の機体 攻撃力 = 遠隔攻撃値

ユニットが受けるダメージ

ダメージ = 攻撃力 × 乱数(80〜120%) − 防御力 // 10以下なら10。外れたら0

防御力（装甲値）は近接攻撃でも遠隔攻撃でも同じように引かれます。

戦艦が受けるダメージ

ダメージ = 攻撃力 × 乱数(80〜120%) // 戦艦の砲撃とビーム機の遠隔攻撃だけ、さらに: ダメージ × 100 ÷ (防御ゲージ × 防御係数 ÷ 1000 + 100)

戦艦には防御力の減算がありません。防御ゲージ（0〜1000）は軽減した分だけ減ります。近接攻撃と実弾の遠隔攻撃は軽減されません。

距離ごとの攻撃力は「15 距離ごとの攻撃力」で、1回のダメージと撃破までの目安は「16 戦闘シミュレーター」で確かめられます。

ヒント ペガサス（防御係数500）の防御ゲージが満タンなら、ビームや砲撃のダメージは約1/6です。ザクやリック・ドムの実弾遠隔攻撃、または取り付いての近接攻撃なら、そのまま通ります。

3命中と回避 ACCURACY

基本命中率 = 75 + 攻撃側（射撃能力 + NT LEVEL + min(移動速, 操縦能力) ÷ 10） − 防御側（回避能力 + NT LEVEL + min(移動速, 操縦能力) ÷ 10） // 35〜95% に収まる // 「命中が距離で下がる」機体の遠隔攻撃のみ（ザク、リック・ドム、ボールなど） 命中率 = 基本命中率 × (1 − 0.5 × 距離 ÷ 最大射程)
  • 命中判定があるのは ユニット同士の攻撃だけです。近接攻撃の命中率は距離で下がりません。
  • 戦艦への攻撃は必ず当たります（ユニットの攻撃も戦艦の主砲も）。
  • ユニットが戦艦に隣接して攻撃すると、先に戦艦の近接武装で迎撃されます。この迎撃は (操縦能力 + NT LEVEL) ÷ 150 の確率でかわせます。
  • ユニット同士の戦闘に反撃はありません。攻撃側だけがダメージを与えます。

機体とパイロットを指定した命中率は「16 戦闘シミュレーター」で計算できます。

戦艦への命令と主砲

  • 旗艦の主砲は指定した目標しか撃ちません。僚艦と敵艦は、目標がいなければいちばん近い見えている敵艦を撃ちます。目標が射程外か見えないときは、今の目標の半分未満の距離に見えている敵艦がいる場合だけ、そちらを撃ちます。戦艦の主砲が自動でユニットを狙うことはありません。
  • 僚艦は毎ミッション「待機」で始まります。「攻撃」「突撃」は目標へ向かい、見失うと「待機」に戻ります。
  • 敵艦・友軍艦のAIは、近くて弱い艦を優先します。輸送艦を優先する処理もありますが、不具合でほぼ働きません（付録A）。「攻撃」は距離50で止まって撃ち合い、「突撃」は近づき続けます。
  • 敵艦のエネルギー配分は状況に応じて自動で変わります。離れていると機関に振って近づき、距離50（攻撃）/30（突撃）に入ると防御と主砲に振ります。
  • 組の先頭の艦（4・8・12番艦）が失われると、後続が撤退するよう設定された艦があります。先頭の艦がまだ到着していないときも「失われた」と扱われるため、増援の後続艦が到着直後に撤退することがあります（付録A）。

6母艦・発進・索敵 CARRIER

発進と収容

  • 発進の条件はパイロットが乗っていることと CONDITION 400以上 だけ。HPや推進剤が減っていても発進できます（ただしHPが50%未満だと、下の自動帰艦ですぐ戻ってきます）。
  • 発進中は1カウントごとに機体の移動速ぶん溜まり、500で艦の周囲8マスに出ます。発進時は移動ゲージ＝操縦能力、攻撃ゲージ＝射撃能力から始まります。
  • 艦内のユニットは1カウントごとに HP +1、推進剤 +1。GM（HP650）を50%から満タンにするには325カウントかかります。
  • 母艦が撃沈されると、艦内と発進中のユニット、控えのパイロットはすべて失われます。外に出ているユニットは、自分からいちばん近いマップ端へ向かって離脱します。
  • AIの艦は、推進剤が満タンで HP が80%以上のユニットだけを発進させます。

ミノフスキー粒子と索敵

  • マスごとにミノフスキー粒子の濃度があります。濃度20未満ならはっきり見え、20〜49なら反応だけ見えます。
  • 濃い場所の敵は、味方艦の索敵範囲（全艦15マス）か味方ユニットの索敵範囲（9〜10マス）に入ると見え、その1.5倍以内なら反応だけ見えます。
  • 旗艦や戦艦の主砲で狙うには、より厳しい条件（濃度20未満、ユニットの索敵範囲内、または艦から15マス以内）が必要です。

自動帰艦のタイミング

ユニットは移動の番が来るたびに（移動ゲージが500溜まるたびに）次の2つを調べ、どちらかに当てはまると命令が「帰艦」に切り替わります。敵・友軍のユニットも同じ規則で動きます。

// 補給: 「補給のため帰艦します」 残りの推進剤 < 母艦までの距離 × 1.3 // 実際の式は 推進剤² < 距離² × 1.69 // 修理: 「修理のため帰艦します」 今の耐久値 < 最大耐久値 ÷ 2（端数切り捨て）
  • 判定は推進剤を1減らす前に行います。距離は母艦のマスまでの直線距離です。1.3倍の余裕があるので、まっすぐ帰れば推進剤は尽きません。
  • すでに「帰艦」中のユニットと、母艦を失った（撃沈・離脱）ユニットは判定しません。母艦を失ったユニットは、自分からいちばん近いマップ端へ向かい、そのまま戦域から離脱します。
  • 別の命令を出し直しても、条件を満たしている限り次の移動の番でまた「帰艦」に戻ります。修理か補給が済むまで、そのユニットを前線に留めることはできません。
  • 帰艦中も、攻撃の番が来れば射程内や隣接の敵を攻撃します。
  • メッセージが出るのは旗艦のユニットだけです。僚艦や敵のユニットは黙って帰ります。
  • 母艦のマスに着くと艦内に入り、命令は「停止」になります。旗艦のユニットは自分で発進させるまで出てきません。僚艦のユニットは、推進剤が満タンで耐久値が80%以上に戻ると、艦のAIが再発進させます。
  • 艦内では1カウントごとに耐久値と推進剤が1ずつ回復します。
ヒント 敵のユニットも耐久値が半分を切ると母艦へ逃げ帰ります。耐久値が半分以下の敵は、母艦に戻られる前に追いかけて仕留めれば撃破数（得点）を稼げます。逆に、自軍のユニットは耐久値が半分を切った時点で戦力外になるので、防御力の低い機体は早めに入れ替えを考えましょう。

下の表は、パイロットの操縦能力が機体の移動速以上の場合です。「推進剤が尽きるまで」は「停止」以外の命令で動き続けたときのカウント数（動かなくても移動の番ごとに1減ります）。「行動半径」は母艦からまっすぐ離れていったとき、補給の帰艦が始まる距離の目安です（斜めに進むと約15%伸びます）。「艦内での回復」は、帰艦ラインちょうど（耐久値50%）から満タンまでと、推進剤0から満タンまでのカウント数です。

第2部キャンペーン

7勝敗と得点 RESULT

戦闘の終わり方

  • ゲームオーバー: 旗艦が撃沈されるか戦域からいなくなったとき。
  • 戦闘終了: 戦域にいる敵艦がすべて撃沈・離脱したとき。まだ来ていない増援は数えないので、増援が来る前に今いる敵艦を片付けると、その時点で終わります。
  • ミッションによっては、友軍艦隊や敵輸送艦がいなくなったときにも終わります。
  • 時間制限はありません。作戦目標を満たせなくても負けにはならず、報告文と分岐が変わるだけです。

得点（功績）

得点 = 敵艦撃沈 × 10 + 敵ユニット撃破 × 3 − 自軍艦の喪失 × 10（輸送艦は20） − 自軍ユニットの喪失 × 3 + ミッションボーナス // 0未満は0

誰が倒したか、戦闘にかかった時間は関係ありません。得点は累計の「功績」と「補充ポイント」の両方に加算されます。

8キャンペーン進行 CAMPAIGN

持ち越されるもの

  • 旗艦に積んでいて撃破されなかったユニットと、生き残ったパイロットだけが次へ持ち越されます。僚艦のユニットはミッションごとに用意されます。
  • ユニットが撃破されると乗っていたパイロットは必ず戦死します（脱出はありません）。
  • ユニットのダメージは持ち越されません。毎回 HP・推進剤満タンで始まります。
  • ブリーフィングを見ないと出撃できません。

9ユニット補充 SUPPLY

補充されるユニットはプレイヤーが選ぶのではなく、ミッションごとの候補から補充ポイントに応じて自動で決まります。ここでは、その決まり方を再現して、ポイントごとの結果を計算します。ルートごとの理論上の最大は「8 キャンペーン進行」のルート別の進行にまとめています。

  • 補充ポイントは戦闘の得点（功績と同じ値）が貯まったものです。
  • 補充があるのは、基地に寄港し、かつ補充候補が設定されているミッションの出撃前だけです。それ以外の寄港ではポイントは持ち越されます。
  • 候補の中でいちばん高い機種から、買えるだけ買い、残りで次に高い機種を買う、を繰り返します。
  • 補充が行われると、余ったポイントは0になります（次に持ち越せません）。
  • 基地で扱えるユニットは、旗艦から降ろした機体と補充された機体を合わせて12機までです。12機目が入った時点で残りのポイントは捨てられます。
  • 補充されたユニットは「ユニット編成」で旗艦に積まないと、出撃時に消えます。

13ランキング RANKING

機体の性能だけで比べた理論値です。パイロットの操縦能力が機体の攻撃速・移動速以上あり、攻撃がすべて当たる前提で、乱数は平均（99.5%）を使います。

攻撃力ランキング

「遠隔攻撃（表示値）」は機体データの遠隔攻撃値です。ビーム機（威力減衰あり）は距離で威力が下がり、遠隔攻撃できるいちばん近い距離2でも表示値より低くなります（コアブースターは 180 → 162）。「実効値（距離2）」で比べると距離2での値、「実効値（最大距離）」で比べると撃てるいちばん遠いマス（距離² が射程値 R 未満で最大のマス）での値、「表示値」で比べると減衰を無視した値を使います。ビーム機は最大距離でおよそ半分になります。実弾機は威力が変わりませんが、ザクやリック・ドムなど「命中が距離で下がる」機体は、最大距離では命中率もおよそ半分になります（このランキングは全弾命中の前提です）。「理論火力」は1回のダメージ×100カウントあたりの攻撃回数です。相手の防御力を選ぶと、1回ごとに引いて計算します（最低10）。

防御力ランキング

「実効耐久」は、選んだ攻撃力の攻撃を受け続けたときに耐えられる攻撃力の合計（耐久値 ÷ 1回の被ダメージ × 攻撃力）。防御力が高いほど、弱い攻撃に強くなります。「回避への上限」は機体の移動速で、パイロットの操縦能力は命中・回避の計算でこの値までしか使われません（÷10 して加算）。

戦艦の攻撃力

主砲の配分を最大（100）にしたとき、主砲ゲージは1カウントに+14溜まり、約72カウントで1発撃てます。主砲は距離で威力が下がり、最大距離（撃てるいちばん遠いマス。艦は距離² が射程値 R 以下なら撃てます）ではおよそ半分になります。

戦艦の防御力

防御ゲージが満タンのとき、ビームと主砲のダメージは 100 ÷ (防御係数 + 100) に減ります。実弾と近接攻撃には効きません。
