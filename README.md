# ガンダムタクティクス MOBILITY FLEET0079 Windows 11 互換パッチ

『ガンダムタクティクス MOBILITY FLEET0079』の 96版 (1996年のオリジナル版) と 01版 (2001年の復刻版) を Windows 11 上で遊べるようにする非公式の互換パッチのソースコードです。

## 対象

| 項目 | 内容 |
| --- | --- |
| タイトル | ガンダムタクティクス MOBILITY FLEET0079 |
| 版 | 96版: オリジナル版 (1996年発売) / 01版: 復刻版 (2001年9月19日発売) |
| ゲーム本来の対応 OS (発売当時) | 96版: Windows 95 / 01版: Windows 95/98/Me |
| パッチの動作環境 | Windows 11 |

Windows 11 で動かすと、プロパティの設定 (互換モード、管理者として実行など) や環境によって、次の問題が起きることがあります。本パッチを当てると、これらを解決できます (プロパティの設定は不要です)。

- 起動時に「16ビットモードで実行してください」のエラーが出る
- BGM・効果音が鳴らない
- ムービーが暗転する、またはスキップされる
- フェード演出の代わりに画面が上下反転する
- 画面内にユニットなどがいないときに、バトルカウントが早送りされない
- 特定のハーバー画面で不自然な縦線が表示される

また、次の機能を加えています。

- ゲーム画面の拡大表示 (ウィンドウのサイズ変更・最大化・Alt+Enter で全画面。v1.1.0 から)
- 96版への対応 (v1.2.0 から)

各バージョンの変更点は [CHANGELOG.txt](release/GundamTactics_Win11Patch/CHANGELOG.txt) を参照してください。

## 利用者向け

ゲーム本体はご自身で用意してください。このリポジトリと配布用 ZIP には、ゲーム本体やゲームのデータは含まれていません。

[GitHub Releases](https://github.com/61bi-234469/gundam-tactics-win11-patch/releases) から配布用 ZIP をダウンロードしてください。導入手順は [README.txt](release/GundamTactics_Win11Patch/README.txt) にあります。

- 96版と 01版の `gundam.exe` は同じファイルなので、1 つのパッチで両方の版に使えます。
- パッチを当てられるのは、未改変の `gundam.exe` と、このパッチの旧バージョンを当てた `gundam.exe` だけです。インストーラーがファイルを照合してから当てます。
- 96版はゲームを CD から起動する方式です。そのため、インストーラーが CD (またはマウントした ISO イメージ) の中身をフォルダ (既定は `C:\GundamTactics96`) へコピーしてからパッチを当てます。コピー後は CD がなくても起動できます。Windows には何もインストールしません。

## 開発者向け

### 構成

| パス | 内容 |
| --- | --- |
| `release/GundamTactics_Win11Patch/` | 配布パッケージのテンプレート (インストーラー・README・CHANGELOG)。DLL はビルド時に追加されます |
| `work/exe_patches/` | `gundam.exe` にバイナリパッチを当てるスクリプト (Phase 1〜5) |
| `work/qtim_proxy/` | QuickTime 互換プロキシ DLL (`QTIM32.dll` / `CMGR32.dll`) とムービーデコーダーのソース。ムービーの暗転・スキップはここで解消しています |
| `work/tools/` | 検証用のツール |
| `work/build_all.py` | パッチ適用、プロキシのビルド、配布 ZIP の作成、リリーステストまでを通しで実行するスクリプト |
| `guide/` | 攻略データのページ (GitHub Pages で公開。`.github/workflows/pages.yml`) |

### ビルドに必要なもの

- Windows 11
- Python 3.10 以上
- MSYS2 MinGW 32bit gcc (既定のパス: `C:\msys64\mingw32\bin\gcc.exe`)
- `source_exe_01/` に置いた、未改変の 01版のインストールファイル一式 (`gundam.exe` の SHA256 は `work/build_all.py` の `EXPECTED_SOURCE_SHA256` で照合されます)

```
python work/build_all.py
```
